# Bypassing the Spectral Approximation: Direct Graph Cuts via Autoregressive Assignment Generation (AutoSC)

Official implementation of **AutoSC**, an autoregressive spectral clustering framework that bypasses the conventional spectral approximation and directly models cluster assignments as a sequence.

AutoSC reformulates graph-based clustering as a sequential assignment generation problem. Instead of computing continuous spectral embeddings followed by k-means, AutoSC directly constructs a supervisory assignment sequence from the affinity graph and trains an autoregressive Transformer to generate cluster assignments.

---

## Overview
AutoSC follows a direct assignment-generation pipeline:

```text
Input features
    │
    ▼
Affinity graph construction
    │
    ▼
Stage 1: Supervisory assignment sequence construction
    │
    ▼
Stage 2: Autoregressive Transformer training
    │
    ▼
Predicted cluster assignments
```

The method contains two main stages:

1. **Assignment Sequence Construction**  
   Construct pseudo cluster assignments and an ordering of samples from the affinity graph.

2. **Autoregressive Assignment Generation**  
   Train a Transformer to generate cluster assignments from the constructed assignment sequence.

## File Structure
Main files:

- `AutoSC.py`  
  The main script. It loads data, constructs the assignment sequence, trains the Transformer, and reports clustering results.

- `assignment_sequence_construction.py`  
  Implements the first stage of AutoSC. It constructs pseudo assignments and the sample order from the affinity graph.

- `dataset.py`  
  Defines `SequenceDataset`, which splits the ordered samples into fixed-length assignment sequences for Transformer training.

- `utils.py`  
  Contains utility functions, including random seed setting, feature loading, affinity construction, Sinkhorn normalization, graph clustering score, and clustering metrics.

- `HFCLIP_Feature_Extract.py`  
  Optional script for extracting image embeddings using a pretrained CLIP ViT-B/32 encoder.

- `requirements.txt`  
  Lists the required Python packages.

## 1. Quick Test with Two-Moons

The easiest way to test the code is to directly run:

```bash
python AutoSC.py
```

If the specified feature files cannot be found, the code automatically falls back to a synthetic two-moons dataset generated by `sklearn`.

This is useful for quickly checking whether the environment and code are working correctly.

The fallback logic is implemented in `AutoSC.py`:

```python
try:
    X, y = load_embedding(cfg.dataset, data_root=cfg.data_root)
except Exception as e:
    print(f"Failed to load dataset: {cfg.dataset}. Error: {repr(e)}. Using sklearn two-moons dataset instead.")
    from sklearn.datasets import make_moons
    X, y = make_moons(n_samples=10000, random_state=cfg.seed)
    cfg.dataset = "TwoMoons"
```

Therefore, you can first run:

```bash
python AutoSC.py
```

without preparing image embeddings.

## Running AutoSC

The main script is:

```bash
python AutoSC.py
```

The main configuration is defined in `AutoSC.py`:

```python
class Config:
    seed: int = 1
    dataset: str = "ImageNet-10"
    data_root: str = "./data_HFCLIP"

    device: str = "cuda" if torch.cuda.is_available() else "cpu"

    len_sequences: int = 128
    batch_size: int = 128
    sequence_fill_last: bool = True

    embed_dim: int = 128
    n_head: int = 8
    n_layer: int = 6

    lr: float = 1e-3
    num_epochs: int = 500

    n_trials: int = 16
    anchor_size: int = 16
    perplexity: int = 200

    sinkhorn_reg: float = 0.2
    sinkhorn_iter: int = 4
```

Important parameters:

- `dataset`  
  Dataset name.

- `data_root`  
  Directory containing pre-extracted embeddings.

- `len_sequences`  
  Length of each assignment sequence used for Transformer training.

- `batch_size`  
  Batch size for Transformer training.

- `n_trials`  
  Number of independent trials for assignment sequence construction.

- `anchor_size`  
  Number of samples assigned at each step during assignment sequence construction.

- `perplexity`  
  Perplexity used for building the affinity graph.

- `sinkhorn_reg`  
  Entropic regularization strength in Sinkhorn normalization.

- `sinkhorn_iter`  
  Number of Sinkhorn iterations.

## AutoSC Stage 1: Assignment Sequence Construction

Stage 1 constructs the supervisory assignment sequence.

The main class is:

```python
AssignmentSequenceConstructor
```

It is used in `AutoSC.py` as:

```python
constructor = AssignmentSequenceConstructor(
    n_clusters=cfg.n_clusters,
    batch_size=cfg.batch_size,
    n_trials=cfg.n_trials,
    perplexity=cfg.perplexity,
    sinkhorn_reg=cfg.sinkhorn_reg,
    sinkhorn_iter=cfg.sinkhorn_iter
)

assignments, order = constructor.fit(X, y)
```

This stage performs the following steps:

1. Build an affinity matrix from input features.
2. Initialize a small set of assigned samples.
3. Compute soft assignments using Sinkhorn normalization.
4. Select hard samples according to assignment confidence.
5. Assign selected samples to clusters.
6. Periodically refine assigned samples.
7. Return pseudo assignments and the sample order.

The output is:

```python
assignments
order
```

where:

- `assignments` are constructed pseudo cluster assignments,
- `order` is the sample order used to build autoregressive training sequences.

The quality of the constructed assignments is printed before Transformer training:

```python
acc, nmi, ari = cluster_metric(y, assignments)
print(f"Constructed assignment quality: ACC={acc:.3f}, NMI={nmi:.3f}, ARI={ari:.3f}")
```

## AutoSC Stage 2: Autoregressive Transformer Training

Stage 2 trains the Transformer on the constructed assignment sequence.

The input tokens are:

```text
[BOS, y_1, y_2, ..., y_{T-1}]
```

The target tokens are:

```text
[y_1, y_2, ..., y_T]
```

The Transformer learns to predict the next assignment token autoregressively.

The training function is:

```python
train_transformer(cfg, train_loader, test_loader)
```

During training, the model uses:

```python
memory = model.visual_proj(x_batch)
bos = torch.full((target_batch.size(0), 1), cfg.BOS, device=cfg.device, dtype=torch.long)
target_seq = torch.cat([bos, target_batch], dim=1)
_, loss = model(memory=memory, tgt_idx=target_seq, targets=target_batch)
```

During evaluation, each sample is assigned independently using the BOS token:

```python
memory = model.visual_proj(x_batch).unsqueeze(1)
preds = model.generate(memory=memory, bos_token=cfg.BOS)
```

## Metrics

The code reports three clustering metrics:

- `ACC`: clustering accuracy after Hungarian matching,
- `NMI`: normalized mutual information,
- `ARI`: adjusted Rand index.

Example output:

```text
Constructed assignment quality: ACC=0.823, NMI=0.761, ARI=0.702

[Stage 2] Training the autoregressive Transformer.
Epoch=0, Loss=..., ACC=..., NMI=..., ARI=...
```
